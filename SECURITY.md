# Security

This repository currently provides a static marketing-site preview. It has no operational authentication, payment processing, CRM connection or enquiry backend.

Please avoid posting credentials, personal data or working exploit details in public issues. Use GitHub's private vulnerability reporting when available. Test only an environment you own or have explicit permission to assess.

See [security review notes](docs/SECURITY-REVIEW.md) for the scope and limitations of the latest assessment. The repository is not a security certification.
